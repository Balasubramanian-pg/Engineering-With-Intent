# Databricks Genie Code Handbook: Executable Labs

This directory contains the production Python scripts, SQL DDL templates, and CI/CD pipelines referenced in **The Databricks Genie Code Handbook 1.0**.

## How to Import into Databricks
1. In your Databricks Workspace, open **Workspace** > **Repos** (or **Git Folders**).
2. Click **Add Repo** and clone this repository.
3. Open any script or notebook directly in your workspace.
